# Smart Winery Management System

A general-purpose, open-source winery operations application for managing production, inventory and related records.

See the [English user guide](docs/USER_GUIDE_EN.md) or [Turkish user guide](docs/USER_GUIDE_TR.md). The Turkish overview is in [README.md](README.md).

On an empty installation, use `admin` / `admin` once from the host computer and immediately choose a new strong password. The bootstrap account is restricted to local access until then.
