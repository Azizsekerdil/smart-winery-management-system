# Smart Winery Management System — User Guide

## First start

1. Install and start the application by following the repository instructions.
2. From the host computer, sign in once with `admin` / `admin`.
3. Replace the temporary password immediately when prompted.
4. Create named staff accounts with the minimum necessary permissions.

Define vineyards, products, lots and storage locations; record production steps and stock movements; review reports and back up records regularly. Never commit production data or API keys. Independently validate calculations and regulatory reports. The software is MIT-licensed and supplied without warranty.
