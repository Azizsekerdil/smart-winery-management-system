# Smart Winery Management System

Open-source production and inventory operations  
MIT License · English and Turkish

---

## Traceable daily work

- Vineyards, products and production lots
- Processing steps and stock movements
- Storage locations and operational reporting
- Role-based staff access and audit records
- Optional local or configured AI assistance

---

## Safe first start

Use `admin` / `admin` once on the host computer, then immediately choose a new strong password. Create named staff accounts, keep API keys out of Git, and back up operational data.
